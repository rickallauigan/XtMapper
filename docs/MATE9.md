# Huawei Mate 9 planning

This is a planning document. The Huawei Mate 9 is the next planned target,
intended as a dedicated Android gaming device. Compatibility with this fork
is not yet validated.

## Planned work

- Validate installation, runtime, and editor usability on the Mate 9.
- Adapt and validate an MLBB profile for the device's landscape workflow.
- Validate keyboard, mouse, and controller input separately.
- Investigate performance for the intended gaming workflow and record
  observations before considering changes.

Keyboard, mouse, controller support, and the adapted MLBB profile are not
confirmed on this device. Performance-oriented investigation does not promise
performance gains or lower latency versus upstream.

See the [compatibility table](../COMPATIBILITY.md) and [roadmap](ROADMAP.md).
