# Roadmap

This fork remains based on [Xtr126/XtMapper](https://github.com/Xtr126/XtMapper).
Planned milestones describe intended work, not confirmed compatibility or
release commitments.

## Milestone 1 — S10e editor compatibility

Status: completed

- Included the small-landscape editor/settings clipping fix in
  [PR #1](https://github.com/rickallauigan/XtMapper/pull/1).
- Manually tested the UI fix on the S10e.
- Kept `keyContainer` mapping coordinates unchanged.

## Milestone 2 — S10e MLBB profile/workflow

Status: planned/in progress

Keyboard and mouse are usable on the S10e. Develop and validate the MLBB
profile and landscape gaming workflow; a finished preset is not yet validated.

## Milestone 3 — Controller/GameSir investigation

Status: planned

Investigate general controller compatibility and GameSir G8/G8+ behavior.
Support is not yet validated.

## Milestone 4 — Huawei Mate 9

Status: planned

Validate the next dedicated gaming target, adapt the MLBB profile, test
keyboard/mouse/controller input, and investigate performance. No performance
gains are promised. See [Mate 9 planning](MATE9.md).

## Milestone 5 — broader cleanup/upstreamability

Status: future

Review fork changes for maintainability, broader device validation, and
potential upstream contributions. No upstream acceptance is implied.
